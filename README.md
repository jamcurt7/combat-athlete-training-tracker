# Combat Athlete Training Tracker

A personal Streamlit app for adaptive strength training, BJJ/Muay Thai fatigue management, readiness tracking, conservative progression, analytics, and downloadable training exports.

## Goals

- Cut from 218 lb to 200 lb
- Maintain strength
- Improve conditioning primarily through BJJ/Muay Thai
- Lift Monday, Wednesday, and Saturday
- Train BJJ/Muay Thai Tuesday, Thursday, Friday, and Sunday

## Features

- Daily readiness check-in
- Adaptive full-body workout generation
- Upper/lower emphasis adjustment
- Light days, recovery days, and accessory days
- Set, rep, weight, and RPE logging
- Conservative progression for main lifts
- SQLite local storage
- Analytics dashboard
- Excel export
- PNG chart export

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
